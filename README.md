# Portfolio Website

Personal portfolio website built with vanilla HTML, CSS and JavaScript and hosted using Firebase.

## Tech Stack

- HTML
- CSS
- JavaScript
- Firebase Hosting
- Firebase Cloud Functions
- SendGrid

## Features

- Responsive portfolio interface
- Project showcase
- Light/dark theme
- Resume download
- Contact form backed by a Firebase Cloud Function
- SendGrid email integration
- Emotion Sound Triggers (Coming soon :D)
